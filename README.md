### 🎓 LearnVault — Personal AI Learning Assistant
`Agentic RAG · Grounded Answers · Adaptive Quizzes`

Agentic full-stack learning assistant that lets students upload lecture notes and textbooks, ask natural-language questions grounded strictly in their course material, get answers with exact page-level citations, and master weak topics through adaptive auto-graded diagnostic quizzes.

**Architecture**
`PDF upload -> PyMuPDF extraction -> parent-child chunking -> MiniLM embeddings -> Qdrant -> 4 bounded agents -> cited answers + quizzes`

**Highlights**
- Hierarchical parent-child chunking with Qdrant retrieval and FlashRank cross-encoder reranking.
- Four bounded agents: Query Router & Rewriter, Corrective RAG, Hallucination & Citation Grader, Adaptive Quiz & Diagnostic.
- Only verified tokens are streamed via SSE; safe refusal when evidence is insufficient.
- 100% deterministic quiz grading with weak-topic detection below 60% accuracy.
- Google sign-in, per-user data isolation, Light / Dark / Green themes, fully responsive UI.
- 273 automated tests (259 passed, 14 skipped for optional Docker services, 0 failures).
